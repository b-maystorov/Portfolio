# Mein Portfolio

Das ist meine persönliche Portfolio-Website, auf der ich mich, meinen bisherigen Werdegang und meine IT-Projekte vorstelle.

Ich mache aktuell eine Umschulung zum **Fachinformatiker für Systemintegration (FISI)** und interessiere mich besonders für Linux, Netzwerke, Windows Server und Systemadministration.

Da ich gerne praktisch lerne, beschäftige ich mich auch außerhalb der Umschulung mit eigenen Projekten und Homelabs. Die Website soll einen kleinen Einblick geben, woran ich arbeite und was ich bisher gelernt habe.

**🌐 [Meine Website besuchen](https://b-maystorov.github.io/Portfolio/)**

## Was gibt es auf der Website?

- **Über mich:** Wer ich bin und warum ich mich für IT interessiere.
- **Lebenslauf:** Mein bisheriger Weg und meine Umschulung.
- **Projekte:** Unter anderem mein Active Directory Homelab, CCNA-Labs und weitere IT-Projekte.
- **Kenntnisse:** Technologien und Themen, mit denen ich bisher gearbeitet habe.
- **Kontakt:** Möglichkeiten, mich zu erreichen.

## Technischer Aufbau

Ich habe mich bewusst für eine einfache statische Website entschieden.

Verwendet werden:

- HTML für die Struktur
- CSS für das Design und die Darstellung auf verschiedenen Bildschirmgrößen
- JavaScript für kleinere interaktive Funktionen
- Git und GitHub für die Versionsverwaltung
- GitHub Pages für das kostenlose Hosting

Die Website benötigt kein Framework und keine Datenbank.

## Lokal starten

Wer sich das Projekt lokal ansehen möchte, kann das Repository klonen und im Projektordner einen kleinen Webserver starten:

```bash
python3 -m http.server 8000 --directory dist
```

Anschließend im Browser öffnen:

http://localhost:8000

Die öffentlichen Website-Dateien liegen im Ordner `dist/`.

## Wie geht es weiter?

Die Website wird sich mit der Zeit weiterentwickeln. Wenn ich neue Projekte abschließe, etwas dazulerne oder Ideen für Verbesserungen habe, werde ich sie entsprechend aktualisieren.

Das Portfolio ist für mich also nicht nur eine persönliche Website, sondern auch ein kleines Projekt, an dem ich weiterarbeiten und Neues ausprobieren kann.
